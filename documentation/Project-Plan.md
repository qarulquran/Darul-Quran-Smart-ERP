# Darul Quran Smart ERP

## Project Overview

Darul Quran Smart ERP is a complete Madrasa Management System designed to manage student information, admission, fees, attendance, examination results, certificates, teachers, finance and administration.

## Main Modules

1. Student Management
2. Admission Management
3. Class Management
4. Attendance System
5. Fee Collection
6. Examination & Result Management
7. Certificate Management
8. Teacher Management
9. Finance Management
10. Dashboard & Reports
11. User Security System

## Development Stack

Frontend:
- React
- Tailwind CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB

## Project Goal

To create a modern, secure and easy-to-use ERP system for Madrasa management.
