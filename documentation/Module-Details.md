# Darul Quran Smart ERP - Module Details

## 1. Student Management Module

### Purpose
Manage complete student information digitally.

### Features

- Add new student
- Edit student information
- Search student
- View student profile
- Upload student photo
- Generate student ID
- Maintain student history
